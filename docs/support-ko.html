iOS, iPadOS 및 macOS용 NewsGator 도움말

도움이 필요하신가요? support@newsgator.app로 메일을 보내 주세요. 답변드리겠습니다.

자주 묻는 질문

왜 스토리가 보이지 않나요?

스토리는 Apple Intelligence로 생성됩니다. 기기에서 이를 지원하지 않거나 꺼져 있어도 NewsGator는 피드를 추가하고 기사를 가져올 수 있지만, 같은 iCloud 계정에 로그인되어 있고 Apple Intelligence가 켜진 다른 기기가 처리해야 스토리가 나타납니다. 상태를 확인하려면 활동 화면을 열거나 원격 처리 요청을 탭하세요. iPhone에서는 처리 가능 기기가 열려 있거나 충전 중일 때까지 대기할 수 있습니다.

계정이 필요한가요?

아니요. 독립 실행 모드에서는 NewsGator 계정이 필요 없습니다. 피드를 추가하고 바로 읽으면 됩니다. 계정은 직접 호스팅하는 NewsGator 서버에 연결하는 서버 모드에서만 사용됩니다.

NewsGator는 어떤 AI를 사용하나요?

독립 실행 모드에서는 Apple Intelligence를 사용합니다. 먼저 Apple Private Cloud Compute를 쓰고, 필요하면 Apple의 온디바이스 모델로 이어집니다. 서버 모드에서는 여러분이 설정한 OpenAI 호환 AI를 서버에서 사용합니다.

NewsGator는 저자를 어떻게 지원하나요?

요약은 무엇을 읽을지 빠르게 판단하도록 도와줍니다. 관심 가는 스토리가 있으면 한 번 탭해 원문 발행처 사이트를 열 수 있고, 여러분의 방문·구독·광고 조회는 실제로 취재한 기자와 매체에 돌아갑니다.

피드와 읽음 상태가 기기 사이에 동기화되나요?

네. 독립 실행 모드에서는 개인 iCloud 계정을 통해 iPhone, iPad, Mac 사이에서 피드와 읽음 상태가 동기화됩니다.

어떤 데이터를 수집하나요?

없습니다. 광고도, 타사 추적기도, 분석도 없습니다. 자세한 내용은 개인정보 처리방침을 확인하세요.
